# Usage Guide

## CLI Commands
- `logloop`: Main interactive interface.
- `npm run dev`: Run the CLI in development mode.

## Dashboard
- `npm run dashboard:backend`: Start the NestJS API.
- `npm run dashboard:frontend`: Start the Next.js UI.
- `npm run preview`: Open dashboard site and start dev mode.

## Context Sync
- `npm run context`: Exports current documentation to `.context/` for AI use.
