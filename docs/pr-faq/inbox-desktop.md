# PR-FAQ — Inbox Mode (Desktop Integration)

## 📌 Press Release

**Logloop introduces Inbox Mode: turning chaotic desktops into structured thinking flows.**

São Paulo, Brazil — Today, Logloop announces *Inbox Mode*, a lightweight workflow that connects file organization with cognitive logging directly in the terminal.

Modern creators and developers constantly deal with fragmented inputs: screenshots, downloads, assets, notes, and temporary files. These items typically accumulate in places like the Desktop, creating visual clutter and mental overload.

Inbox Mode transforms this chaos into a simple, repeatable system:

- A single entry point (`_inbox`)
- A fast processing ritual
- Automatic logging of intent and context

With a single command:

```
/inbox
```

Logloop enters a focused mode where users:

1. See their current inbox
2. Log what they are doing (intent)
3. Process files into meaningful destinations

Unlike traditional file managers, Inbox Mode does not try to manage files — it captures **why actions happen**.

This creates a living timeline of decisions, turning daily cleanup into a source of insight.

---

## ❓ FAQ

### 1. What problem does Inbox Mode solve?

People don’t struggle with file organization — they struggle with **decision fatigue** and **lack of context**.

Inbox Mode solves:

- Desktop clutter
- Lost files context ("where did this come from?")
- Mental overhead when organizing files

---

### 2. How is this different from a Downloads/Desktop folder?

Traditional folders store files.

Inbox Mode creates a **processing system**:

- Everything goes into one place
- You process in batches
- You log intent while doing it

---

### 3. Why integrate this with Logloop?

Because organization without context is fragile.

Logloop captures:

- What you were doing
- Why you were doing it
- When it happened

This creates a **timeline of work**, not just a folder structure.

---

### 4. Is this a file manager replacement?

No.

Inbox Mode is intentionally minimal.

It does NOT:
- Move files automatically
- Enforce structure
- Replace Finder/Explorer

It ONLY:
- Creates a ritual
- Captures intent

---

### 5. What does the user experience look like?

```
/inbox

📥 Inbox:
- abrinq-assets.zip
- dpz-layout.psd
- screenshot.png

› organizing abrinq assets
› moving dpz files
› deleting old screenshots
```

Each line becomes a log entry.

---

### 6. How often should users use it?

- 1x per day (recommended)
- or whenever inbox feels cluttered

The key is **frequency over perfection**.

---

### 7. What makes this powerful long-term?

Over time, users build:

- A history of decisions
- Patterns of work
- Insight into where time and attention go

Inbox Mode turns small actions into **traceable cognition**.

---

### 8. Why is this important?

Developers and creators track:

- Code (Git)
- Tasks (Notion, Jira)

But they don’t track:

→ **their thinking while working**

Inbox Mode bridges that gap.
