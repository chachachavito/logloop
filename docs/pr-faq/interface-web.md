# 🧠 PR-FAQ — Logloop Web Interface

## 📰 Press Release

**Logloop lança interface web para transformar logs de terminal em memória navegável e colaborativa**

São Paulo, Brasil — Hoje, o Logloop anuncia sua nova interface web, expandindo sua proposta de capturar o “porquê” por trás do código para além do terminal.

Até agora, desenvolvedores usam o Logloop diretamente no terminal para registrar pensamentos, decisões e contexto durante o desenvolvimento. Com a nova interface web, esses logs passam a ser organizados, pesquisáveis e compartilháveis — criando uma camada viva de documentação que evolui junto com o projeto.

A interface web funciona como um dashboard de contexto do projeto — permitindo visualizar timelines de decisões, buscar rapidamente por contextos passados e entender a evolução do trabalho sem depender de commits ou memória humana.

“Git mostra o que mudou. O Logloop mostra por quê.” — agora também fora do terminal.

A nova experiência inclui:

- Timeline visual de logs por projeto
- Busca semântica por contexto
- Agrupamento automático por sessões de trabalho
- Integração com repositórios Git
- Compartilhamento de contexto com equipes

A interface web do Logloop estará disponível em beta para usuários early adopters nas próximas semanas.

## ❓ FAQ (Frequently Asked Questions)

### 1. O que é a interface web do Logloop?

É um dashboard de contexto que transforma seus logs de terminal em uma interface visual navegável, onde você pode explorar, buscar e entender o histórico de decisões do seu trabalho ao longo do tempo.

---

### 2. Isso substitui o uso no terminal?

Não. O terminal continua sendo o principal ponto de captura.

A interface web é o lugar onde você:
- revisita
- organiza
- compartilha

---

### 3. O que eu consigo ver na interface?

Um dashboard com visão consolidada do seu trabalho:

Você terá acesso a:

- Linha do tempo dos seus logs
- Sessões de trabalho agrupadas automaticamente
- Logs vinculados a commits e branches
- Insights sobre sua evolução no projeto

---

### 4. Como os logs são organizados?

Os logs são agrupados automaticamente por:

- Sessões (blocos contínuos de trabalho)
- Branch do Git
- Intervalo de tempo
- Contexto semântico (futuro)

---

### 5. Dá pra buscar logs antigos?

Sim — e esse é um dos principais pontos.

Você poderá buscar por:

- palavras-chave
- termos técnicos
- decisões (ex: “por que usei Redis aqui?”)
- erros passados

---

### 6. Isso funciona com qualquer projeto?

Sim. O Logloop é agnóstico — funciona com qualquer stack, desde que você use o CLI para registrar logs.

---

### 7. Meus dados ficam públicos?

Não por padrão.

Você terá controle total sobre:
- projetos privados
- compartilhamento por link
- permissões (futuro: equipe)

---

### 8. Isso substitui documentação?

Não — mas reduz drasticamente a necessidade de documentação manual.

O Logloop cria uma documentação orgânica baseada no seu fluxo real de trabalho.

---

### 9. Qual o diferencial disso vs Notion / README / comentários?

Essas ferramentas exigem disciplina manual.

O Logloop captura contexto **no momento em que ele acontece**, sem quebrar seu fluxo.

---

### 10. Vai ter colaboração em equipe?

Sim (roadmap).

A ideia é permitir:
- onboarding mais rápido
- transferência de contexto entre devs
- histórico de decisões acessível

---

### 11. Como isso se conecta com Git?

A interface vai correlacionar logs com:

- commits
- branches
- momentos do desenvolvimento

Criando uma narrativa completa do projeto.

---

### 12. Quando estará disponível?

Beta fechado nas próximas semanas.
