Frequently Asked Questions

Does Logloop replace Git?

No. Git tracks code changes. Logloop tracks the reasoning behind them.

Does it work without Git?

Yes, but it becomes much more powerful when combined with Git.

How does the Brain learn?

It adapts to your writing patterns locally over time.

What does --commit do?

It links your log entry directly to a Git commit.

Does any data leave my machine?

No. Everything is stored locally. No external services involved.

Can I sync across machines?

Yes, using your own tools like Git or cloud storage.
