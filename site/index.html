Deep Integration

O Logloop v0.1.0 introduz o **Loop Contínuo de Contexto**. A ferramenta é desenhada para permanecer aberta em um terminal dedicado, servindo como uma "caixa preta" de decisões.

Common Questions

O help sumiu? Não, ele apenas entra em Zen Mode. Use /h para ver o cabeçalho e os comandos novamente.

Como o Logloop aprende? Ao usar /as <categoria> ou /feel <mood>, você treina o seu cérebro local. O Logloop prioriza suas correções passadas sobre as regras padrão.

Meus dados saem da máquina? Não. O motor 3-Layers (Memory, Fuzzy, Heuristics) é 100% local e privado.

Como editar um log? Digite /e dentro do loop para abrir seu editor favorito.
